# BraqueBoard

Personal desktop companion (macOS) for my own World of Warcraft: Forever character: quests, bags, professions, equipment and session planning, on a second screen.

Read-only, no game automation, no memory reading. The source code is private.

## Data

Quest, dungeon, class and profession data: [Data from ForeverDB.net](https://foreverdb.net). Shown with this credit wherever it appears in the app.
